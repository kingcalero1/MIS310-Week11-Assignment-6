# MIS310-Week11-Assignment-6
## Week 11 - Daily Steps Tracker

This was a class assignment where I built a simple program to track daily steps for a week.

The program asks for a daily steps goal, records steps for 7 days, and then calculates the weekly average.

---

## What the program does

- Asks the user for a daily steps goal
- Records steps for 7 days
- Calculates the weekly average
- Compares the average to the goal
- Displays feedback based on performance

---

- How to use functions in Python
- Working with loops
- Using if/elif/else statements
- Breaking a program into smaller parts
